# Web 個人データ保護レビュー (Web Personal Data Protection Review)

Web サービス固有。ユーザーの個人データ・プライバシーの取扱いがポリシー・法令・
LUDIARS のデータ配置ルール ([`RULE.md`](../RULE.md) §5) と整合しているかを評価する。

> - 暗号化・アクセス制御の実装強度は [REVIEW_VULNERABILITY_WEB.md §3](REVIEW_VULNERABILITY_WEB.md) を参照。
> - ローカルアプリのセンシティブ情報は [local-app/REVIEW_PRIVACY_POLICY.md](../local-app/REVIEW_PRIVACY_POLICY.md) を参照。

## 1. 個人データの分類・最小化 (Data Classification & Minimization)

| データ種別 | 保存場所 | 保持期間 | 根拠 (必要性) |
|-----------|---------|---------|--------------|
| | | | |

### チェック項目

- [ ] サービスが扱う個人データのインベントリ（種別 / 保存場所 / 保持期間）が `spec/data/` にあるか
- [ ] 個人データを各サービス DB に持たず、Cernere を単一情報源としているか（RULE.md §5。`id` FK アンカーのみ保持。`check-personal-data.mjs` が CI で機械検査）
- [ ] 業務上不要なデータを収集・保持していないか（データ最小化原則）
- [ ] ログ・分析基盤・キャッシュ・バックアップへ個人データが無制限に複製されていないか

## 2. 同意・法令遵守 (Consent & Compliance)

| 規制 | 適用有無 | 対応状況 | 所見 |
|------|---------|---------|------|
| GDPR | 有 / 無 | 対応済 / 要対応 / 未対応 | |
| 個人情報保護法 | 有 / 無 | | |
| 業界規制 | 有 / 無 | | |

### チェック項目

- [ ] 適用される法令・規制が特定されているか
- [ ] プライバシーポリシーが提示され、収集目的・第三者提供の記載が実装の実態と一致しているか
- [ ] Cookie / トラッキングの同意取得（オプトイン）と撤回手段があるか
- [ ] データ越境移転（保存リージョン / 外部 SaaS の所在地）の制約を満たしているか
- [ ] 漏洩インシデント発生時の通知義務・対応手順が定義されているか

---

## 3. 保持・削除 (Retention & Erasure)

### チェック項目

- [ ] データ種別ごとの保持期間が定義され、超過分の自動削除があるか
- [ ] ユーザーが自分のデータをエクスポート・削除できる手段があるか（データポータビリティ / 忘れられる権利）
- [ ] 削除がバックアップ・レプリカ・キャッシュ・検索インデックス・外部連携先へ伝播するか
- [ ] 退会・解約時のデータの扱い（即時削除 / 猶予期間 / 匿名化）が定義されているか

---

## 4. 第三者提供・テレメトリ (Third-Party Sharing & Telemetry)

### チェック項目

- [ ] 外部送信するデータと送信先（解析 / 広告 / エラートラッキング / サブプロセッサ）が文書化されているか
- [ ] 送信前のマスキング・匿名化・集約が行われているか
- [ ] サブプロセッサ（SaaS / CDN / 監視サービス）の規約・契約が個人データの取扱いをカバーしているか
