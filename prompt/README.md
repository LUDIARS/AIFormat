# prompt/ — 実行プロンプト集

AIFormat のフォーマット群 (`REVIEW.md` / `FORMAT_SPEC.md` 等) を、実行モデル (Sonnet 5 等) に
**上位モデルと等価の品質で実行させる**ためのプロンプトを集約する。
デイリーレビュー・PR レビュー・AUTOFIX の実行時に、該当ファイルのコードブロックを
タスク指示としてそのまま与える。

| プロンプト | 用途 | 成果物 |
|-----------|------|--------|
| [`REVIEW_FULL.md`](./REVIEW_FULL.md) | フルレビュー (デイリー / リリース前。リポジトリ全体) | `review/<日付>/` 一式 + `latest.json` |
| [`REVIEW_PR.md`](./REVIEW_PR.md) | PR 差分レビュー (REVIEW.md「軽量プロファイル」) | PR インラインコメント + サマリ |
| [`SPEC_GAP.md`](./SPEC_GAP.md) | 仕様欠落の検知 + spec 自動生成 (デイリーレビュー / AUTOFIX 連携) | 検知レポート + spec 生成 PR |

## 共通の設計原則

- **フォーマット (何を見るか・何を書くか) の正本は各 `REVIEW*.md` / `FORMAT_*.md`。**
  プロンプトは**実行規律 (どうやるか) だけ**を規定する。食い違う場合は正本が優先。
- 実行モデルの既知の失敗モードを、手順で構造的に塞ぐ:
  - 評価インフレ (印象で A/B を付ける) → 重大度からの機械導出のみに固定
  - 幻覚 `file:line`・記憶による引用 → 現物再確認の反証パスを必須化
  - チェックボックスの形式的 ON → 項目ごとの証拠・検索ログを必須化
  - 大規模リポでの読み飛ばし → 読む前にカバレッジ計画、未読は「未確認」明記
  - 「対象外」への逃げ → 対象外 / 未確認 / 指摘の三分法を強制
  - 事実の創作 (spec 生成時) → コードを ground truth とし、不明点は TODO 明示
- プロンプトを追加するときは本 README の表に登録し、対応する正本ドキュメントへ
  リンクを張る (プロンプト単体で完結させず、正本と分業する)。
