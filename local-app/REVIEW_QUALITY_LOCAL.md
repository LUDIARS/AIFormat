## 1. パフォーマンス (Performance)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | 起動時間 (cold / warm) | |
| A~D | メモリ使用量 | |
| A~D | CPU / GPU 消費 | |
| A~D | バッテリー消費・発熱 | |
| A~D | UI 応答性 | |

### チェック項目

- [ ] 起動時間（cold / warm）が許容範囲か
- [ ] アイドル時の CPU・メモリ消費が過大でないか（バックグラウンド常駐の妥当性）
- [ ] 大きなファイル・大量データ処理時に UI がフリーズしないか（重い処理の非同期化）
- [ ] メモリリーク・ハンドルリークがないことが確認されているか
- [ ] ノート PC でのバッテリー消費・発熱が考慮されているか
- [ ] 低スペック端末での動作が検証されているか

## 2. クロスプラットフォーム互換 (Cross-Platform Compatibility)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | パス・ファイルシステムの扱い | |
| A~D | OS 別 API の抽象化 | |
| A~D | 文字エンコーディング・改行コード | |
| A~D | インストーラ・配布形態 | |
| A~D | コード署名・公証 | |
| A~D | CI でのマトリクス実行 | |

### チェック項目

- [ ] パスを `/` ハードコードせず OS 非依存に組み立てているか
- [ ] ファイル名の大文字小文字・予約名・パス長制限を考慮しているか
- [ ] OS 別 API（通知 / トレイ / ファイルダイアログ / 自動起動）が抽象化されているか
- [ ] CRLF ↔ LF・文字エンコーディングの OS 差を考慮しているか
- [ ] 各 OS 向けのインストーラ / アンインストーラが用意されているか
- [ ] 各 OS のコード署名・公証（Notarization）要件を満たしているか
- [ ] CI が Windows / macOS / Linux マトリクスで実行されるか
- [ ] arm64 / x86_64 等のアーキテクチャで動作確認されているか
- [ ] OS 別のインストール前提（ランタイム / ライブラリ）が README に記載されているか

---

## 3. アクセシビリティ・国際化 (Accessibility & i18n)

### チェック項目

- [ ] OS のアクセシビリティ設定（スクリーンリーダー / ハイコントラスト / 文字拡大 / モーション軽減）に追従するか
- [ ] 主要フローがキーボードのみで操作でき、ショートカットが提供されているか
- [ ] UI 文言がハードコードされず i18n 機構経由か（対象ロケールが定義されているか）
- [ ] IME 経由の入力・多言語のファイル名 / パスを正しく扱えるか
- [ ] 日付・数値・タイムゾーンの表示がロケールに応じて整形されているか

> CLI 専用ツール等で GUI を持たない場合、GUI 前提の項目は「対象外」とし、
> 出力の機械可読性・NO_COLOR 対応等を代替観点として所見に記載する。
