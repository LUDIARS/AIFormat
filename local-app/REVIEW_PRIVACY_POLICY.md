# センシティブ情報取扱いポリシーレビュー (Sensitive Information Handling Policy Review)

ローカルアプリ固有・**必須項目**。
ローカルアプリはセンシティブ情報（個人情報・認証情報・業務機密・健康情報等）を扱う前提のため、
取扱いポリシーが定義され、実装がそのポリシーと整合しているかを評価する。

## 1. センシティブ情報の分類・棚卸し (Data Classification & Inventory)

アプリが扱う全データを洗い出し、機微度で分類する。

| データ種別 | 機微度 | 保存場所 | 保持期間 | 暗号化 |
|-----------|--------|---------|---------|--------|
| | 公開 / 内部 / 機密 / 最高機密 | メモリ / ディスク / OS セキュアストレージ / 外部 | | 有 / 無 |

### チェック項目

- [ ] アプリが扱う全データのインベントリが作成されているか
- [ ] 各データが機微度（公開 / 内部 / 機密 / 最高機密）で分類されているか
- [ ] 各データの保存場所が特定されているか
- [ ] 業務上不要なデータを収集・保持していないか（データ最小化原則）
- [ ] 機微度に応じた取扱いルールが文書化されているか

## 2. 保存データの保護 (Data at Rest)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | ディスク暗号化 | |
| A~D | OS セキュアストレージの利用 | |
| A~D | 暗号鍵の管理 | |
| A~D | 一時ファイル・キャッシュの扱い | |

### チェック項目

- [ ] 機微データがディスクに平文で保存されていないか
- [ ] 認証情報・トークンを OS のセキュアストレージ（Keychain / Credential Manager / libsecret 等）に保存しているか
- [ ] 暗号鍵がデータと同じ場所・同じ権限で保存されていないか
- [ ] 一時ファイル・キャッシュ・スワップ・ダンプに機微データが残留しないか
- [ ] アンインストール時に機微データが確実に削除されるか

---

## 3. メモリ上の機微データ (Data in Use)

### チェック項目

- [ ] パスワード・鍵等を使用後にメモリからゼロクリアしているか
- [ ] コアダンプ・クラッシュダンプに機微データが含まれない設定になっているか
- [ ] クリップボード経由の機微データに有効期限・自動クリアがあるか
- [ ] スクリーンショット・画面録画・画面共有からの保護（機微画面のマスク）が検討されているか
- [ ] 機微データがログ・標準出力・デバッグ出力に漏れていないか

---

## 4. 第三者送信・テレメトリ (Data in Transit & Third Party)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | 送信先の最小化 | |
| A~D | 明示的同意（オプトイン） | |
| A~D | 通信の暗号化 | |
| A~D | 匿名化・マスキング | |

### チェック項目

- [ ] 外部送信するデータと送信先が文書化されているか
- [ ] テレメトリ・解析・クラッシュレポートの送信がオプトイン（明示同意）になっているか
- [ ] 送信前に機微情報がマスク・匿名化・集約されているか
- [ ] 通信が TLS 1.2+ で暗号化され、証明書検証を無効化していないか
- [ ] 同意の確認・撤回手段がユーザーに提供されているか
- [ ] 外部送信が利用規約・プライバシーポリシーの記載と一致しているか

---

## 5. ログ・診断情報 (Logging & Diagnostics)

### チェック項目

- [ ] ログに機微情報（パスワード / トークン / 個人情報）が出力されていないか
- [ ] ログのマスキング・フィルタ機構が実装されているか
- [ ] ログの保存期間・ローテーション・アクセス制御が定義されているか
- [ ] クラッシュレポートに機微データが含まれないことが検証されているか
- [ ] サポート向けに収集する診断情報の範囲がユーザーに開示されているか

---

## 6. データ保持・削除 (Retention & Erasure)

### チェック項目

- [ ] データ種別ごとの保持期間が定義されているか
- [ ] ユーザーが自分のデータをエクスポート・削除できる手段があるか（データポータビリティ / 忘れられる権利）
- [ ] 保持期間を超過したデータの自動削除があるか
- [ ] 機微データの削除が論理削除でなく確実な物理削除（上書き含む）になっているか
- [ ] バックアップ・同期先からの削除も伝播するか

---

## 7. アクセス制御・認証 (Access Control)

### チェック項目

- [ ] アプリ起動・機微機能アクセス時に OS アカウント / 生体認証 / アプリロックを要求できるか
- [ ] 同一端末の別ユーザー・多重起動から機微データへのアクセスが制限されているか
- [ ] 一定時間操作がない場合の自動ロック・自動ログアウトがあるか
- [ ] 認証失敗時のロックアウト・試行回数制限があるか

---

## 8. 法令・規制遵守 (Compliance)

| 規制 | 適用有無 | 対応状況 | 所見 |
|------|---------|---------|------|
| GDPR | 有 / 無 | 対応済 / 要対応 / 未対応 | |
| 個人情報保護法 | 有 / 無 | | |
| 業界規制（HIPAA / PCI DSS 等） | 有 / 無 | | |

### チェック項目

- [ ] 適用される法令・規制が特定されているか
- [ ] 業界固有規制（医療 / 金融 等）への対応要否が検討されているか
- [ ] プライバシーポリシー・利用規約がユーザーに提示され、同意取得されているか
- [ ] データ越境移転（海外サーバへの送信）の制約を満たしているか
- [ ] インシデント（情報漏洩）発生時の通知義務・対応手順が定義されているか
- [ ] 監査・開示請求に応えられる記録が残されているか
