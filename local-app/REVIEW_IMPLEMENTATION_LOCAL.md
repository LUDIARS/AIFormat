## 1. ローカルデータストア (Local Data Store)

ローカル DB・設定ファイル・状態ファイルの妥当性を検証する。

| ストア / ファイル | 問題種別 | 説明 | 推奨対応 |
|-----------------|---------|------|---------|
| | 破損耐性不足 / 重複 / 型不整合 / マイグレーション欠如 | | |

### チェック項目

- [ ] ローカル DB（SQLite 等）のスキーマが正規化され、マイグレーション機構があるか
- [ ] スキーマバージョンと後方互換（古いバージョンのデータを読めるか）が管理されているか
- [ ] 設定ファイルのフォーマット・デフォルト値・破損時のフォールバックが定義されているか
- [ ] 書き込み中のクラッシュ・電源断でデータが破損しないか（アトミック書き込み / WAL）
- [ ] 同時起動インスタンス間の排他制御があるか
- [ ] データファイルの保存先が OS の標準ディレクトリ規約に従っているか

---

## 2. バックアップ・移行 (Backup & Migration)

### チェック項目

- [ ] ユーザーデータのバックアップ・エクスポート手段があるか
- [ ] 別マシン・別 OS へのデータ移行が可能か
- [ ] インポート時の入力検証・バージョン互換チェックがあるか
- [ ] バックアップデータの暗号化が機微度に応じて行われているか

---

## 3. 運用信頼性 (Operational Reliability)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | 自動更新の信頼性 | |
| A~D | クラッシュ復旧 | |
| A~D | 可観測性（ログ・診断） | |
| A~D | オフライン動作・同期 | |
| A~D | 環境異常のハンドリング | |

### チェック項目

- [ ] 自動更新が失敗した際にロールバック可能か
- [ ] クラッシュ後の再起動でデータ・編集中の状態が復元されるか
- [ ] クラッシュレポート・診断ログが収集されるか（機微情報を除外して）
- [ ] オフライン時の動作と、オンライン復帰時の同期競合解決が定義されているか
- [ ] ディスク容量不足・権限エラー・ファイルロック等の環境異常をハンドリングしているか
- [ ] バージョン・環境情報がサポート向けに取得できるか

**評価基準**（重大度の定義・導出ルール・対象外の扱いは [REVIEW.md「評価の決定ルール」](../REVIEW.md#評価の決定ルール) を正本とする）:
