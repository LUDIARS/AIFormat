## 1. ゲームパフォーマンス (Game Performance)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | フレームレート安定性 | |
| A~D | フレームタイムのスパイク（ヒッチ / スタッター） | |
| A~D | メモリ予算 | |
| A~D | ロード時間・シーン遷移 | |
| A~D | 描画最適化（ドローコール / バッチング / LOD） | |

### チェック項目

- [ ] ターゲットフレームレート（30 / 60 / 120fps）が定義され、最低スペックで達成されているか
- [ ] フレームタイムのスパイク（ヒッチ / スタッター）が計測・抑制されているか
- [ ] GC を持つ言語の場合、ゲームループ中のアロケーションが最小化されているか
- [ ] メモリ予算がプラットフォーム別に定義され、超過していないか
- [ ] ロード時間・シーン遷移時間が許容範囲か
- [ ] ドローコール・バッチング・LOD・カリングが最適化されているか
- [ ] プロファイラ（CPU / GPU / メモリ / フレーム）での計測が行われているか
- [ ] 低スペック端末・長時間プレイ時のサーマルスロットリング・メモリ増大が考慮されているか

## 2. プラットフォーム互換 (Platform Compatibility)

| 評価 | 観点 | 所見 |
|------|------|------|
| A~D | 対応プラットフォーム要件 | |
| A~D | 入力デバイス対応 | |
| A~D | 画面・解像度・アスペクト比 | |
| A~D | ストア / プラットフォーム認証要件 | |
| A~D | 中断・復帰・フォーカス制御 | |

### チェック項目

- [ ] 対応プラットフォーム（PC / コンソール / モバイル）ごとの要件が整理されているか
- [ ] 複数の入力デバイス（キーボード / マウス / ゲームパッド / タッチ）に対応しているか
- [ ] 各種解像度・アスペクト比・セーフエリア（ノッチ等）に対応しているか
- [ ] 各プラットフォームの認証要件（コンソール TRC / XR、ストアガイドライン）を満たしているか
- [ ] 中断・復帰（サスペンド / レジューム）、フォーカス喪失・バックグラウンド遷移への対応があるか
- [ ] プラットフォーム別の保存先・実績・課金 API が抽象化されているか
- [ ] プラットフォーム別ビルドが CI で生成・検証されているか
